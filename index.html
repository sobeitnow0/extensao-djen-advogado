Política de Privacidade

Última atualização: Abril de 2026

A extensão "Buscador DJEN" foi desenvolvida com o compromisso absoluto de respeitar a privacidade e a segurança da informação dos seus usuários, em total alinhamento com os princípios da Lei Geral de Proteção de Dados (LGPD). Esta política descreve como os dados são tratados.

1. Coleta e Uso de Dados

O desenvolvedor desta extensão não coleta, não armazena em servidores externos, não rastreia e não tem acesso a nenhum dado pessoal, histórico de navegação, número de OAB ou conteúdo de processos pesquisados pelos usuários.

2. Armazenamento Local

Todas as informações fornecidas na extensão (como Número da OAB, UF, configurações de notificações e a agenda de prazos salvos) são armazenadas estritamente de forma local no próprio dispositivo do usuário, utilizando a API nativa chrome.storage.local do navegador.

3. Comunicação com APIs de Terceiros

Para o seu funcionamento, a extensão comunica-se de forma direta e criptografada (via HTTPS) apenas com:

  • API Pública do CNJ (comunicaapi.pje.jus.br): Para realizar a busca das intimações utilizando os parâmetros informados pelo usuário.
  • Repositório Público (raw.githubusercontent.com): Apenas para consultar a base de dados em formato JSON contendo os feriados nacionais e municipais, de forma a garantir o cálculo correto dos prazos processuais.

A extensão atua apenas como uma ponte direta entre o computador do usuário e estas bases públicas.

4. Compartilhamento de Dados

Como nenhum dado é coletado pelo desenvolvedor, nenhuma informação do usuário é vendida, alugada ou compartilhada com terceiros sob qualquer circunstância.

5. Contato

Em caso de dúvidas sobre esta Política de Privacidade ou sobre o funcionamento da extensão, entre em contato através do e-mail: adv.amilcarmoreira@gmail.com.
