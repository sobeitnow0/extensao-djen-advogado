Integrações Google (Agenda & Tasks)

Configure sua conta para sincronizar prazos fatais e criar tarefas automáticas.

📅 Google Agenda
☑️ Google Tasks NOVO

Permite enviar prazos processuais diretamente para a sua lista de tarefas do Google com lembrete e data fatal calculada.

▶ Como configurar o Google Apps Script? (Passo a Passo)
  1. Acesse script.new e faça login com sua conta Google.
  2. Cole o código: Apague todo o código padrão e cole este: 
    function doPost(e) {
  try {
    var dados = JSON.parse(e.postData.contents);
    var novaTarefa = { title: dados.title || 'Tarefa', notes: dados.notes || '' };
    if (dados.due) novaTarefa.due = dados.due;
    var tarefa = Tasks.Tasks.insert(novaTarefa, '@default');
    return ContentService.createTextOutput(JSON.stringify({ status: 'sucesso', id: tarefa.id }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (erro) {
    return ContentService.createTextOutput(JSON.stringify({ status: 'erro', mensagem: erro.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  3. Ativar a API do Tasks: No menu lateral esquerdo, clique em Serviços (+), encontre Google Tasks API e clique em Adicionar.
  4. ⚠️ Autorizar (passo obrigatório): Na barra superior, clique em Executar. O Google vai pedir permissão — clique em Revisar permissões e autorize. Sem este passo, a integração não funciona.
  5. Implantar: Clique em Implantar → Nova implantação. Clique no ícone ⚙️ e escolha App da Web.
  6. ⚠️ Em "Quem pode acessar": Selecione Qualquer pessoa (sem restrição de login — a opção com "com login do Google" NÃO funciona).
  7. Clique em Implantar, copie a URL do App da Web e cole no campo acima. Clique em Salvar Webhook.

📚 Guia rápido

Guia rápido para configuração e uso otimizado do Buscador DJEN na sua rotina.
✨ Novidades da Versão
  • Layout Mais Limpo: Cards de intimação totalmente redesenhados. A data de disponibilização, tags e ícones de tarefas agora ficam organizados na base do cartão.
  • Marcação Inteligente: O estilo de "Lido" (transparente) é removido automaticamente assim que você calcula e salva um prazo.
  • Calculadora Instantânea: Removemos a dependência de buscas automáticas lentas no CNJ durante o cálculo. Agora a calculadora responde em milissegundos.
  • Referências Legais em Hover: As informações sobre contagem (CPC, CLT, CPP) não poluem mais a tela. Basta passar o mouse sobre o tipo de matéria para ler as regras.
🚀 Primeiros Passos & Buscas
  • Configuração OAB: Insira sua OAB e Estado nas configurações (Menu) para otimizar as buscas oficiais.
  • Busca Inteligente: Pode colar o processo com ou sem pontos, o sistema formata automaticamente para o padrão CNJ (20 dígitos).
  • Modo Foco: Nos resultados, clique no ícone do quadrado () para ler publicações extensas em tela cheia, sem distrações.
⏱️ Calculadora & Auditoria Avançada
  • Motor Híbrido: Selecione "Cível" ou "Trabalhista" para contagem em dias úteis (CPC/CLT) ou "Criminal" para dias corridos (CPP). Passe o mouse sobre a seleção para ler a regra completa.
  • Integração IBGE e GitHub: A calculadora detecta feriados nacionais, estaduais e municipais automaticamente, bastando informar a comarca.
  • Prova de Tempestividade: Ao calcular um prazo, clique no resultado para expandir a "Grelha de Dias". Exporte a auditoria em PNG para anexar nas suas petições.
🎯 Radar de Urgências & Tags
  • Radar Automático: Termos vitais (como "Penhora", "Revelia", "Liminar") geram alertas coloridos na tela. Você pode personalizar estas palavras-chave no Menu de Opções.
  • Tags Manuais: Selecione qualquer texto dentro do teor de uma publicação. Isso criará automaticamente uma #tag_personalizada nas anotações do processo.
⌨️ Atalhos de Teclado
  • ESC — É o seu botão de pânico. Fecha abas, sai do modo foco, recolhe modais e reseta calculadoras, tudo de forma progressiva.
  • Enter — Expande ou recolhe o cartão de intimação quando ele está selecionado.
🛡️ Privacidade & Base Offline

Sigilo Absoluto: O DJEN funciona 100% no seu navegador. Nenhuma intimação, nota de cliente ou prazo é enviado para os nossos servidores.

Portabilidade: Use a opção "Salvar Backup" no Menu para baixar toda a sua base de dados num ficheiro seguro. Use "Restaurar Backup" para transferir o seu escritório para outro computador num piscar de olhos.
